# Day 9 Review Notes – Mixed Practice & Weak Domain Analysis

## 1. Purpose of Day 9

Day 9 focuses on:
- Broad, mixed-domain practice.
- Identifying weak areas across all CSSLP domains.
- Reinforcing concepts through targeted review.
- Updating artifacts based on insights from practice tests.

This day is about consolidation, not learning new material.

---

## 2. Mixed Practice Testing

### Recommended Practice Volume
- 100–125 mixed questions across all domains.

### Goals
- Evaluate readiness for the exam.
- Identify recurring mistakes.
- Understand which domains require deeper review.
- Practice reasoning under exam-like conditions.

### What to Track
- Score per domain.
- Types of mistakes (conceptual, process, lifecycle, terminology).
- Time spent per question.
- Confidence level vs correctness.

---

## 3. Categorizing Mistakes

### Common Mistake Categories
- Misinterpreting lifecycle phases.
- Confusing functional vs non-functional requirements.
- Incorrect threat-to-mitigation mapping.
- Over-focusing on technical details instead of process.
- Misunderstanding governance and roles.
- Weakness in supply chain concepts (SBOM, dependency risk).

### How to Categorize
1. Create a table with columns: Domain, Question Type, Mistake, Root Cause.
2. Assign each missed question to a domain.
3. Identify patterns (e.g., repeated STRIDE errors, requirement mapping issues).
4. Document findings in `domain_weakness_analysis.md`.

---

## 4. Reinforcing Weak Domains

### Recommended Actions
- Revisit the corresponding DayXX folder.
- Re-read review notes and artifacts.
- Update diagrams (DFDs, architecture diagrams, SDLC workflows).
- Add missing requirements or controls to SRTM.
- Expand misuse/abuse cases if needed.
- Strengthen test cases for weak areas.

### Example Reinforcement
If weak in Domain 3 (Architecture):
- Re-check trust boundaries.
- Re-run STRIDE on critical data flows.
- Add missing mitigations.

If weak in Domain 8 (Supply Chain):
- Expand SBOM entries.
- Add more dependency risk analysis examples.
- Review vendor assessment criteria.

## 7. Practice Question Notes

### Common Observations
- Many questions test lifecycle alignment (which phase, which role).
- Architecture and supply chain questions are often the most challenging.
- Requirements and testing questions rely heavily on traceability.
- Implementation questions focus on secure coding principles rather than syntax.

### Strategy Adjustments
- Slow down on scenario-based questions.
- Focus on reasoning rather than memorization.
- Revisit domains with more than 20% incorrect answers.
