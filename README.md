# 🛡️ CSSLP Learning Repository  
A complete, hands‑on, 10‑day preparation for the **ISC² Certified Secure Software Lifecycle Professional (CSSLP)** certification.

This repository blends **exam‑focused study**, **secure SDLC artifacts**, and **real hands‑on security work** across all eight CSSLP domains. It is designed to serve both as a learning log and a professional portfolio demonstrating practical software security skills.

---

## 📚 What This Repository Contains
- A structured **10‑day CSSLP study plan**
- Hands‑on artifacts: threat models, SRTM, SBOM, secure design diagrams, SAST/DAST results
- Domain‑specific notes and exercises
- A complete secure SDLC mini‑project
- Templates, diagrams, and checklists aligned with CSSLP best practices

## 📝 Practice Strategy
- 20–30 questions per domain  
- 100–125 mixed questions on Day 9  
- Categorize mistakes by domain  
- Reinforce weak areas  
- Focus on reasoning, not memorization  

---

## 💡 CSSLP Exam Tips
- Think like a **security architect**, not a pentester  
- Prioritize **requirements, design, and supply chain**  
- CSSLP is **process‑heavy** — governance matters  
- Avoid overly technical rabbit holes  
- Sleep well before exam day
